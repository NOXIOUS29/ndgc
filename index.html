# NĐGC — Underground Music Collective Portfolio

Website giới thiệu chính thức cho nhóm nhạc underground **NĐGC (New Wave / Hyperpop / Underground)**.

## 🚀 Cấu trúc File (Production Structure):
```
/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   │   ├── noxious.jpg
│   │   ├── hexxo.jpg
│   │   ├── thokawi.jpg

```

## 🛠️ Hướng Dẫn Deploy GitHub Pages:
1. Đưa toàn bộ file lên Repository trên GitHub.
2. Vào **Settings** -> **Pages**.
3. Chọn Branch `main` hoặc `master` và thư mục `/ (root)`.
4. Nhấn **Save**. Website sẽ hoạt động ngay lập tức không cần build step!
